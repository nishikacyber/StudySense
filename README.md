StudySense – Smart Study Planner

StudySense is a console-based study planning application developed using the C programming language. It helps students organize their academic tasks, track study progress, monitor daily consistency, and stay updated about upcoming examinations.

~ Features

1.Subject Management: Add and manage academic subjects.

2.Task Management: Create and view study tasks.

3.Task Completion: Mark tasks as completed.

4.Progress Tracking: Monitor completed and pending tasks.

5.Study Streak: Track consecutive days of study activity.

6.Exam Countdown: Calculate the days remaining until upcoming exams.

7.Interactive Dashboard: View important study statistics in one place.

8.Data Persistence: Save subjects, tasks, and activity records using file handling, so information remains available after restarting the application.
